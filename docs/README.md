# Docs

Start with [architecture.md](architecture.md): the components, their contracts and the decision
register.

- [roadmap.md](roadmap.md): milestones, backlog and non-goals.
- [design/](design/): one design doc per milestone, written before it is implemented.
- [adr/](adr/): architecture decision records, one per decision that is costly to reverse.
- [style.md](style.md): style rules the linters cannot check.
- [tasks/testing.md](tasks/testing.md) and [tasks/render-tests.md](tasks/render-tests.md): how
  to run the tests, headless runs and updating the golden images.
- [modules/](modules/) and [tasks/pull-requests.md](tasks/pull-requests.md): context for the
  coding agent, an addendum to [AGENTS.md](../AGENTS.md). One doc per component, and the repo's PR
  rules; the front matter is what the agent's knowledge retrieval matches on. Readable, but written
  for the agent.
- [media/](media/): recordings and screenshots for the README.
